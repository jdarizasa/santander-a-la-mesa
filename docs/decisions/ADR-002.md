## ADR-0002: Estructura ETL

- Estado: aceptado
- Fecha: 06/11/2026

### Contexto
Dado que muchos datasets se actualizan anualmente no es necesario llamarlos constantemente. Hacer esto puede ralentizar la app y gastar innecesariamente energía.

### Solución
Se usará Github Actions para agendar el llamado de datos cada cierto tiempo (mínimo 6 meses). Quedarán listos los scripts fetch_.py para que se actualizen los parquets con los nuevos datos publicados por el gobierno.
